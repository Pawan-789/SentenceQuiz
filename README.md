# Sentence Construction Quiz

A dynamic, interactive quiz application built with TypeScript and React that tests users' knowledge of sentence construction. The app features a clean, modern UI styled with Tailwind CSS and includes a timer for each question.

## Features

- 🎯 Multiple-choice questions focusing on sentence construction
- ⏱️ Timer for each question to add excitement
- 👤 Personalized experience with user name input
- 📊 Detailed results and performance analysis
- 💫 Smooth animations and transitions
- 📱 Fully responsive design

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone [https://github.com/Pawan-789/SentenceQuiz.git]
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

## How to Play

1. **Enter Your Name**
   - Start by entering your name to personalize your quiz experience
   - Click "Start Quiz" to begin

2. **Quiz Rules**
   - Each question has a 60-second timer
   - Select the correct answer from multiple choices
   - Questions focus on proper sentence construction and grammar
   - You cannot change your answer after submission
   - Skipping questions is not allowed

3. **Scoring**
   - Correct answers: +10 points
   - Incorrect answers: 0 points
   - Time bonus: Up to 5 extra points based on response speed

4. **Results**
   - View your total score
   - See detailed performance analysis
   - Review correct and incorrect answers
   - Option to retry the quiz
